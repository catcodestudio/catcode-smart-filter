# CatCode Smart Filter for WooCommerce

A faceted product filter that stays fast on a large catalogue: its own index table, honest counts and no reload on every click.

This repository mirrors the free version published on wordpress.org, version 1.1.1.

## Requirements

- WordPress 6.2+ (tested up to 7.1)
- WooCommerce 6.0+ (tested up to 10.7)
- PHP 7.4+

## Install

Install from the WordPress plugin directory (Plugins → Add New → search for the plugin name), or download this repository and upload it to `wp-content/plugins/catcode-smart-filter/`.
